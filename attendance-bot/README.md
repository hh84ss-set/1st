# Doosan 근태계획변경 자동화 봇

`mytime.doosan.com`의 "근태계획변경" 화면에서 하는 일(날짜 선택 → 기존 근태 삭제 → 근무유형/시간 입력 → 신청)을
Playwright로 자동화하고, 채팅으로 "오늘 근무시간 8시30분부터 17시까지로 변경" 같은 자연어 명령을 보내면
Claude가 이 스크립트를 알맞은 옵션으로 실행해주는 구조입니다.

## 동작 방식

1. 출근길에 클로드 모바일 앱으로 이 세션(또는 이 세션에 연결된 Routine)에 자연어로 명령을 보냅니다.
   예: "오늘 근무시간 8시30분 부터 17시 00분 까지로 변경"
2. Claude가 문장에서 날짜/근무유형/시작·종료시간을 해석해서
   `node src/apply.js --date 2026-07-23 --type 근무 --start 08:30 --end 17:00 --submit` 형태로 실행합니다.
   (자연어 파싱은 Claude가 직접 하고, 스크립트는 이미 구조화된 값만 받습니다 — 별도의 한국어 파서를 두지 않았습니다.)
3. 스크립트가 로그인 → 근태계획변경 진입 → 대상 날짜 이동 → 기존 항목 삭제 → 신규 항목 입력 → 신청까지 수행합니다.

## 설치

```bash
cd attendance-bot
npm install
cp .env.example .env   # DOOSAN_AD_ID / DOOSAN_AD_PW 채워넣기
```

Playwright가 사용할 Chromium은 이 환경에 이미 설치되어 있습니다
(`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`, `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1` 이미 설정됨 — 별도 `playwright install` 불필요).

## 사용법

```bash
node src/apply.js --date 2026-07-23 --type 근무 --start 08:30 --end 17:00
```

`--submit` 없이 실행하면 **화면 입력까지만 하고 "신청" 버튼은 누르지 않는 dry-run**으로 동작하며,
`run-logs/<타임스탬프>/` 아래에 단계별 스크린샷을 남깁니다. 실제 사이트에서 확인 후 이상 없으면
`--submit`을 붙여서 실제 신청까지 진행하세요.

```bash
node src/apply.js --date 2026-07-23 --type 근무 --start 08:30 --end 17:00 --submit
```

사용 가능한 `--type` 값은 `src/workTypes.js`에 정의되어 있습니다: 근무, 연차, 반차, 반반차, 시간차,
1년미만-연차, 1년미만-반차, 1년미만-반반차, 1년미만-시간차, 교육, 국내출장, 해외출장, 재택근무.

## ⚠️ 알아두어야 할 것

- **이 환경(Claude Code 원격 실행 환경)의 아웃바운드 네트워크 정책이 현재 `mytime.doosan.com`을 차단하고 있습니다.**
  실제로 로그인/신청이 되려면 이 세션이 속한 환경의 네트워크 정책에서 해당 도메인을 허용해야 합니다.
- 이 스크립트의 로그인 폼, 월 이동 화살표, 삭제(X) 버튼, "추가"/"선택"/"신청" 버튼 selector는
  캡처 화면만 보고 최선으로 추정해 작성한 것이라 **실제 사이트로 한 번도 검증되지 않았습니다.**
  코드 안에 `TODO(실제 사이트 검증 필요)` 로 표시해 두었으니, 네트워크가 열리면 `HEADFUL=1`로 한 번
  실행해서 각 단계 스크린샷을 확인하고 깨지는 부분을 고쳐야 합니다. `#geuntae_cd`, `#add_sta_time0`,
  `#add_end_time0` 세 개는 실제 HTML을 그대로 받아 만들어서 신뢰도가 높습니다.
- 근무유형에 따라 "상세사유"가 필수일 수 있습니다(예: 연차/출장 등). 필요하면 `--reason` 옵션을 넘기세요.
- AD 계정 비밀번호는 채팅으로 보내지 말고 `.env`(git에 커밋되지 않음)에만 저장하세요.
- `run-logs/`에는 근태 화면 스크린샷(개인 근무기록)이 쌓이므로 `.gitignore`에 포함되어 있고, 커밋하면 안 됩니다.
