01

프로젝트 개요

반복적인 고객 문의를 자동으로 응대하고, 처리가 어려운 건은 상담원에게 자연스럽게 연결하는 AI 챗봇 솔루션을 구축합니다. 기존 FAQ와 상담 이력을 학습해 답변 정확도를 높이고, 운영자가 대화 로그와 통계를 직접 관리할 수 있는 대시보드를 함께 제공합니다.

02

구축 범위 및 주요 기능

자연어 FAQ 자동응답

자주 묻는 질문을 의도(intent) 단위로 분류하여 자동 응답

시나리오 기반 상담 흐름

업무별 상담 절차를 대화 흐름으로 설계 및 구현

LLM 연동 답변 생성

정형 답변 외 영역은 LLM이 문맥에 맞게 답변 생성

상담원 핸드오프

챗봇 처리 불가 건을 상담원에게 매끄럽게 인계

관리자 대시보드

대화 로그 조회, 답변 수정, 이용 통계 확인

채널 연동

웹, 카카오톡 채널 연동 및 기존 CRM 연계 API
