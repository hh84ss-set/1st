# ⛳ 골프 쇼츠 자동 제작기

골프장에서 찍은 아이폰 사진·영상을 폴더에 넣으면 날짜·골프장·날씨를 뽑아 1분 쇼츠를 만들고,
YouTube 에 올리고, 종합소득세 장부(Google Sheets)에 기록하는 것이 목표입니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 메타데이터 추출 (촬영시각, GPS, 크기·회전, 영상 길이) | ✅ `media.py` |
| 2 | 골프장 이름(Kakao), 그날 날씨(Open-Meteo), 자막 문구 | ✅ `enrich.py`, `round.py` |
| 3 | 9:16 영상 합성 + 자막 + BGM | 예정 |
| 4 | YouTube Shorts 업로드 | 예정 |
| 5 | Google Sheets 장부 (수입·비용·자산·콘텐츠) | 예정 |

## 준비 (Python 3.11+)
```bash
pip install -r golf_shorts/requirements.txt   # Pillow, pillow-heif(아이폰 HEIC)
```
- **FFmpeg**: 영상 메타데이터(ffprobe)와 3단계 합성에 필요합니다. Windows 는 `winget install ffmpeg`, Mac 은 `brew install ffmpeg`.
- **Kakao REST API 키** (골프장 이름 검색, 무료)
  1. https://developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가
  2. 앱 설정의 앱 키(플랫폼 키) 화면에서 **REST API 키** 복사
  3. **카카오맵** 사용 설정을 ON (2024년 12월 이후 만든 앱은 로컬 API 를 쓰려면 필요)
  4. 저장소 루트에 `.env` 파일을 만들고 `KAKAO_REST_API_KEY=복사한키` 한 줄 저장 (`.gitignore` 에 포함되어 커밋되지 않음)
- 날씨(Open-Meteo)는 키가 필요 없습니다.

## 사용법
```bash
python -m golf_shorts.round ./2026-10-25
```
```
⛳ 2026.10.25 (일) | 남여주CC | ☀️ 맑음 · 14~19℃ · 바람 3m/s
   사진 23개 · 영상 9개 · 07:42~12:18
   → 2026-10-25/round.json
```
- `--course "남여주CC"`: 골프장 이름 직접 지정 (검색 결과가 틀리거나 GPS 가 없을 때)
- `--offline`: API 호출 없이 메타데이터만 추출

`round.json` 에는 날짜, 라운드 시간대, 골프장, 날씨(기온 범위·평균 풍속·돌풍·강수량), 자막 문구,
파일별 촬영시각·좌표·세로 여부·영상 길이, 경고 목록이 들어갑니다. 3~5단계는 이 파일을 읽습니다.

## 아이폰에서 PC 로 옮길 때 (위치·시각 보존)
| 방법 | GPS·촬영시각 |
|---|---|
| USB 연결 후 사진 가져오기, AirDrop, iCloud 사진 '수정되지 않은 원본 다운로드' | ✅ 유지 |
| 공유 시트로 보낼 때 상단 **옵션 → 위치** 켜기 | ✅ 유지 |
| 카카오톡·메신저 전송, 스크린샷 | ❌ 삭제됨 → `--course` 로 지정 |

카메라 앱 위치 권한이 꺼져 있으면 처음부터 GPS 가 기록되지 않습니다: 설정 → 개인정보 보호 → 위치 서비스 → 카메라 → '앱을 사용하는 동안'.

## 판단 기준
- 여러 날짜가 섞여 있으면 파일이 가장 많은 날을 라운드 날짜로 보고 나머지는 경고로 알립니다.
- 위치는 GPS 있는 파일들의 좌표 중앙값입니다. 그 좌표에서 3km 안의 가장 가까운 '골프장' 카테고리 장소를 고르고
  (연습장·스크린골프 제외), 없으면 행정구역(예: 경기도 여주시)으로 표시합니다.
- 날씨는 첫 촬영 시각~마지막 촬영(영상이면 끝나는 시각)의 시간별 값을 집계합니다. 강수 시간이 1/3 이상이면
  비·눈을, 아니면 가장 흔한 하늘 상태를 대표 날씨로 씁니다. 최근 80일은 Open-Meteo forecast(관측 반영),
  그 이전은 archive(ERA5 재분석)를 씁니다. 기상청 ASOS 관측값이 필요하면 이후 교체할 수 있습니다.
