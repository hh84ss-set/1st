# 카드 이미지 폴더

`aipri-memory.html`은 이 폴더의 공식 이미지를 사용합니다.

- `oa4/` — 『おねがいアイプリ 4だん』 카드 58장 (`OA4-001.webp` …)
- `chara/` — 플레이어 아바타용 캐릭터 얼굴 13장

이미지는 타카라토미 아츠의 저작물이라 저장소에는 올리지 않습니다(`.gitignore`).
개인적으로 즐기는 용도로만 쓰고, 필요할 때 아래 스크립트로 공식 사이트에서 다시 받으세요.

```bash
pip install pillow
python3 cards/fetch_official.py
```

게임 화면의 "내 카드 추가하기"에서 가지고 있는 다른 카드 사진을 올릴 수도 있습니다(브라우저에만 저장).
