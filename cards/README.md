# 카드 이미지 폴더

`aipri-memory.html`은 이 폴더의 이미지를 기본 카드로 불러옵니다.

1. 카드 이미지(PNG/JPG/WEBP)를 이 폴더에 넣습니다. 세로형(3:4 비율 정도)이 잘 맞습니다.
2. `manifest.json`에 파일 이름을 적습니다.

```json
{
  "cards": [
    { "file": "inori-01.webp", "name": "이노리" },
    { "file": "aoi-01.webp", "name": "아오이" }
  ]
}
```

- 서로 다른 그림 24장 이상이면 48장(24쌍)이 모두 실제 카드가 되고, 24장보다 많으면 판마다 무작위로 24장을 고릅니다.
- 게임 화면에서 이미지를 바로 올릴 수도 있습니다(브라우저에만 저장).
- 공식 카드 이미지는 저작권이 있습니다. 개인이 즐기는 용도로만 쓰고, 외부에 배포하기 전에는 사용 허락을 확인하세요.
